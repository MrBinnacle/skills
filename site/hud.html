Binnacle HUD: a heads-up display for Claude Code and Pi

A thought is not a prompt.

Keep your thoughts. Choose what becomes context. See what surfaces.

Your coding agent is working, and you have a thought. A concern about the design. Something to revisit. A decision you have not made yet. It does not need to become the next prompt.

Binnacle HUD gives those thoughts a place beside the session. Keep them in the Log. Send the Memory you want the agent to keep. See observations from the session as they surface.

Boxes are places a thought, a line or a note can be. A solid arrow always happens. A dashed arrow depends on a rule. The double box is a confirmation you answer. The horizontal line is where the agent’s context begins. These are diagrams, not screenshots.

Three paths, three rules

The paths run side by side. A Log thought can stay a Log thought. A Memory line does not have to start in the Log. A note starts in the session, not with you. Each host keeps its own wording, so the limits below are per host.

Log

Keeping a thought starts no agent turn.

Claude Code
Type in the HUD’s field and press Enter. From the Claude app on your phone, send /log alone and type the thought in the dialog under Other; text typed after /log goes into the conversation. The mod keeps the thought in session state and does not send it to Claude. Whether a thought stays out of a later model request has not been verified. Other plugins in the session can read the Log.
Pi
/log <text> or the HUD menu. A test that runs Pi’s real agent loop with scripted model replies captures every request and checks that no Log thought reaches one.

Memory

You see the exact lines before they go. Sending is not the same as arriving.

Both
Edits you make while the question is open stay in the draft and do not change this Send. Memory lasts for the session; a new session starts empty.
Claude Code
After Send the panel says “Sent at HH:MM. Not yet in Claude’s instructions.” It says “In Claude’s instructions since HH:MM.” only after its hook has added exactly those lines to Claude Code’s memory section. Another plugin could still change that section, and the hook cannot tell whether the prompt was built for a subagent. A Send makes Claude Code rewrite its prompt cache once. That the lines survive a real compaction follows from where they sit; it has not been observed.
Pi
The line above the editor says “Memory sent”, then “Memory in instructions” once a request’s system section equals the approved text. The end-to-end test checks that sent Memory reaches the agent after /compact. Sending an empty Memory withdraws it.

Heads-ups and Observer

A note can reach the agent without you pressing anything. Whether it does depends on the host.

Claude Code
The mod takes the heads-ups that Claude Code’s built-in side agent offers and gives each one to Claude with no key press. At most one note starts a turn for each message you send; later notes go with your next message. The mod tells Claude to weigh each note and act on it if it holds; nothing asks you first. A note can repeat text that reached the session from files, tool output or web pages, and how far the mod’s framing lowers the chance that Claude follows a planted instruction has not been measured. This mod’s route has not yet run in a live session.
Pi
A second model call reads the new turns after every 6 agent turns, or when the agent hands back with at least 3 unread, and raises a note only when it can quote the record. Until you change it, the observer runs in panel mode: the note stays with you, and the observer never starts a turn on its own. Your Send from the menu can. In forward mode a note also goes to a busy agent before its next model call, or to an idle one with your next message, unless the observer judged the agent already knows it.

What was checked

This page has no screenshots yet. The figures are diagrams drawn from the code, not captures of a session.

  • Pi. The consent rules run end to end against Pi’s real agent loop, session store and extension loader, with only the model’s replies scripted. With the unit tests beside it, the suite fails on each of eleven faults planted in the code (Pi 1.6.1, 2026-11-26).
  • Claude Code. On 2.1.319, a thought kept from the phone left the session at 0 turns, and a conversation export held the /log command and its reply but not the thought. The Memory mechanism reached the model on the next turn in a headless probe on 2.1.325.
  • Not checked. The Claude Code heads-up route in a live session, Claude Code Memory after a real compaction, and the Pi overlay in a live terminal. Each README lists the rest.

Inspect the transitions

Install in Claude Code

On Claude Code 2.1.275 or later, run this at the prompt:

/plugin install binnacle-hud --marketplace MrBinnacle/skills

On an older Claude Code, run /plugin marketplace add https://github.com/MrBinnacle/skills.git, then /plugin install binnacle-hud, one at a time. If the marketplace is already added, run claude plugin marketplace update mrbinnacle-skills in a shell first. Then run /reload-plugins or start a new session.

First use: turn on /tui fullscreen in a window at least 110 columns wide and run /hud. Type a thought and press Enter: it is in the Log, and no turn starts. Type a line, press Tab, then a to add it to Memory, and s to send it. Claude Code shows the lines and asks before they go; choose Send.

Install in Pi

The HUD installs with the rest of the package. Use the install command in the README.

First use: press alt+h or run /hud. /log <text> keeps a thought. /hud add <line> adds a Memory line, and /hud send sends Memory after you confirm the lines.
