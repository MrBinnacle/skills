What the record holds

Admission policy
Four questions decide whether a card enters. The default answer is no.
Retirement record
A card that leaves is recorded, with the reason it left.
Evidence per card
Each card carries its own record. A figure nobody measured is written down as missing, not filled in.

What a version promises

The install path and the card format are what a version promises. The set of cards is not. Cards are added and retired under a minor release, so what you can install is expected to change.

The decision record says why. The changelog says what changed.
