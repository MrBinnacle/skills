# Orchestration skills

Disciplines for multi-agent work: dispatch, joinability, and synthesis across parallel agents. This bucket installs as the `mrbinnacle-orchestration` plugin, and its [`plugin.json`](.claude-plugin/plugin.json) is the authoritative list of what it installs. Each card's `EVIDENCE.md` records where the card came from and what has and has not been measured; an installed card is not thereby shown to work.

A card marked *(by hand)* sets `disable-model-invocation: true`, so it runs only when you invoke it by name, as `/mrbinnacle-orchestration:<card>`. It is below the always-on bar in [ADR 0008](../../docs/adr/0008-always-on-needs-two-occasions-or-a-controlled-result.md). The other cards load in every session.

- [**decision-rights**](decision-rights/SKILL.md) *(by hand)* — when you write a handoff, plan, ADR or subagent brief, or one says "do not re-litigate" or "final", test per decision who holds the evidence that bears on it: frame revisable decisions as proposals with a "Revisit if:" clause, and keep values decisions and explicit constraints non-negotiable, since better evidence licenses a revisit request and not a scope change ([the receipt](decision-rights/EVIDENCE.md)).
- [**disposition-schema**](disposition-schema/SKILL.md) — when parallel agents verify or adjudicate a shared set of findings, give every seat the same closed decision vocabulary, per-item output block, item ownership, status line and namespaced finding IDs, so their isolated outputs join at synthesis without a silently dropped finding; includes the adversarial-verify seat template ([the receipt](disposition-schema/EVIDENCE.md)).
- [**subagent-handback**](subagent-handback/SKILL.md) — before dispatching a subagent for research, whether web, literature or a read-only sweep of the local repository, name a return channel you can read without trusting the handback (`SendMessage` or a file at one path) and check that its tool grant can do the task; when it returns, verify every claim you will act on, negatives first and over a wider search than the agent used ([the receipt](subagent-handback/EVIDENCE.md)).
