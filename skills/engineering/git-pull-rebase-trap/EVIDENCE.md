| **Enforcement note (verified 2026-08-12)** | Two flavors, and they are not the same. An error-signature hook is *reactive*: it surfaces recovery after a bad pull. Prevention must inspect the command and effective rebase config before the pull; model-pull cannot guarantee that, and a proactive loop has no retrieval turn. The card is therefore the model-invocable reference for trap explanation, prevention-by-recipe, and recovery, while executable enforcement stays in the adopter's environment. Its loop-native recipe is a Claude Code `PreToolUse` block; its non-harness recipe is a shell wrapper because Git 2.54.0 exposes no pre-pull client hook. Runtime claims checked against the live [Claude Code hooks reference](https://code.claude.com/docs/en/hooks) and Git 2.54.0 [`githooks`](https://git-scm.com/docs/githooks/2.54.0), [`pull`](https://git-scm.com/docs/git-pull/2.54.0), and [`config`](https://git-scm.com/docs/git-config/2.54.0) manuals. |
