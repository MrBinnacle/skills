The front-door line is now "Less prompting. Better plumbing." It replaces "Skills that started with problems I encountered." on `README.md`, both README banners, the landing page, the `package.json` description and the repository social preview. A design critique on 2026-11-24 found that a first-time reader could not tell from the old line what "skills" or "I" meant. The new line says what the repository does differently: its guards change what a coding agent can do, instead of adding instructions it may ignore. The social preview was rebuilt at the same time. It now shows the `MRBINNACLE / skills` wordmark, sets the address as a plain footer instead of a boxed panel, keeps the mark inside the safe margin, and is exported without the coloured fringes the old image had around its letters.
