The Binnacle HUD no longer warns that a Send was missed after a turn you stop or one an API error ends. Such a turn can end before Claude Code asks for the memory section, so it says nothing about whether the Send arrived. The mod now checks delivery only after a turn the model answered or refused. The mod also gains a listing icon, and seven test files are renamed after the behaviour they test.
