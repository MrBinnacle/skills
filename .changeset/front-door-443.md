The README, the landing page and the social preview now describe Skills as a knowledge base and a set of skill cards for engineering work with frontier models, and link the knowledge base from the front door. They say that Pi is the runtime this work targets first and that there is no tested Pi install yet. The `npx skills add MrBinnacle/skills` line is gone from the README and the social preview, because no receipt shows what it installs from the current tree. The README install section now states, for Windows, the measured limit on the length of the Claude configuration directory path (`CLAUDE_CONFIG_DIR`), what `git config --global core.longpaths true` changes, and the conditions of that measurement (#452). This entry changes no cards. One other change in 3.1.0 asks some installed users to act. If you copied the detector code from the `pretooluse-prose` card (`_CMD_POS`, `HEREDOC_RE` or `split_shell_and_body`) into a hook of your own, copy it again: the earlier `HEREDOC_RE` swallowed every command after a `<<-` heredoc whose closing line is tab-indented, and `_CMD_POS` read a `;` inside quotes as a separator (#405). If you did not, you need do nothing.
