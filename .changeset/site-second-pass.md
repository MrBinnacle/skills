The landing page gets a second pass from the design critique of 2026-11-24, which scored it 17 of 24. On a phone the demo picture's text rendered about 3px high, so below 768px the page now hides the picture, and wider screens keep it. A link that opens the picture full size shows at every width, and it is the only keyboard stop for the picture. The demo instructions on the page and in `README.md` now start with `git clone https://github.com/MrBinnacle/skills.git` and `cd skills`, because the demo runs from a clone. The header carries a GitHub link, "Pi" links to pi.dev, the page ends with the README's Contribute paragraph, and a click on a command selects all of it. The skip link's focus ring is no longer cut off at the top of the window. A printed page shows each outside link's address and leaves out the dark picture. The logo grows with text-only zoom. Body text lines now run at most about 80 characters at 1440px, down from 88 to 97. The footer drops the skill-harness link, and "How it is kept" ends with a link to the README. `scripts/validate_site_links.py` now checks `src` as well as `href`, and resolves a relative path through the `cp` lines in `.github/workflows/pages.yml`, so a picture the deploy would not publish fails the check. That includes a file in the root `assets/` folder that `pages.yml` does not copy, and a `../` path that leaves `site/`. The docstring of `scripts/check_release_public.py` now says its Pi check compares pins, not whether the recorded install passed.
