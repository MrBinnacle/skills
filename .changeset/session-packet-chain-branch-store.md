The session-packet mechanism gains four opt-in behaviours. With none configured, it behaves exactly as before, and the 89 existing `bun test` tests pass unchanged. `headPolicy: "ancestor"` lets the receiver accept a packet HEAD in four cases: the HEAD is reachable from the current HEAD, it is reachable from origin's default branch, its branch still exists on origin, or the branch was squash-merged and deleted (an injectable probe, by default `gh pr list --state merged`). Any other moved HEAD is `HEAD drift`, with the failed routes listed. A missing `gh` or an unreachable origin adds a note and never turns drift into a pass. Produce mode keeps an exact HEAD. `chain: true` records `previous_packet_id` and replaces the unclaimed-HEAD refusal, so a session may close without a new commit. Two packets with the same parent are reported as two heads, and both are kept. A manifest may carry `parked[]` entries (`branch-exists`, `remote-branch-exists`, `stash-exists` by commit SHA, never `stash@{n}`, and `worktree-exists`), and receive mode probes each one. `store: { kind: "branch", ref }` commits each accepted packet to an orphan branch through a private worktree (default `var/session-log-worktree`, kept out of `git status` through `.git/info/exclude`) and pushes it. A failed push warns, and the next open reports `packet unpushed`. A non-fast-forward is resolved by fetch and rebase. Open reads the newest packet from the local store branch or from origin's. The store's commit and push bypass the repository's hooks with `--no-verify`, so the gate on those bytes is a scan that runs on the exact blob before it is staged. That scan refuses a possible secret or an email address, and then nothing is committed. Creating the store needs git 2.42 or later, and an older git is refused with that version named. `skills/engineering/im-down/PACKET-FORMAT.md` and its im-up twin document the two optional manifest fields. `validate_packet.py` ignores both fields and still accepts such a packet in produce and receive mode. `bun test` in `mechanisms/session-packet` runs 136 tests across 10 files.
