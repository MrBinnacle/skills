# Project method

Choose the smallest useful structure. An issue is one actionable outcome; a project coordinates multiple deliverables; an initiative connects strategic projects; milestones represent meaningful checkpoints; cycles are team timeboxes; documents hold durable knowledge; status updates report progress at a point in time.

Search for existing work before creating anything. Inspect the target team, statuses, labels, templates, cycles, milestones, issues and relationships. Define outcome, problem evidence, scope, exclusions, observable acceptance criteria, dependencies and ownership. Keep unknown product intent explicit.

For a project, create issues only for actionable deliverables. Add milestones only for meaningful gates and dependencies only when one task must finish before another can proceed. Set dates, owners, priority, labels and cycles only when supported by the request or workspace evidence.

When changing an existing project, read it and its related work first. Reuse objects rather than duplicate them. Preserve fields not named in the request. For broad or consequential changes, show a concise before/after plan first. For each planned write, name the read-back that would show the write did nothing: the field still holds its old value, the relation is absent, the status update does not appear on the project. Run that read-back after the write, as a fresh query against the workspace, not from the write call's own response. A write tool's success message is the write reporting on itself. If a prerequisite fails, stop dependent writes.

For issue descriptions, capture problem/evidence, intended outcome, scope/exclusions, observable acceptance criteria, true blockers and unresolved questions. Do not convert every observation into a ticket.

Report progress evidenced, work in flight, blockers, risks, decisions needed and next actions. A status is a signal, not proof. Missing evidence means unknown, not absent, unused or complete. Separate verified facts, inferences, recommendations and unsupported claims.
