## [OBSERVED] 2026-08-25 — two competent sweeps agreeing is one blind spot sampled twice

Two prior-art sweeps ran in separate sessions on the same question. Both returned real, correct,
citable applied-layer material. Their agreement read as corroboration and raised confidence.

It was not corroboration. Both had the same search posture, so they had the same blind spot, and
running it twice produced consistency rather than coverage. One of them went on to record that the
criterion under study "does not reduce to prior art" — a claim refuted in one pass by asking what
the applied answer was an instance of.

**Rule:** repeated agreement between sweeps of the same *kind* is not independent confirmation.
Vary the LAYER, not just the query.

## [OBSERVED] 2026-08-25 — the skill's own author walked into its second face the same day

Within hours of extracting this pattern, the same session grepped a tool's SKILL.md for the word
`init`, got zero hits, and stated aloud that the tool had no setup flow and its config file would
have to be hand-authored. Both halves were wrong: the capability sat in the command table under
the name `teach`, and the tool's own preflight explicitly forbade hand-authoring that file.

**Rule:** knowing this pattern does not inoculate against it. The failure feels like a completed
check, not like a shortcut, which is exactly why it needs an external trigger rather than
self-discipline.

## [ANTICIPATED] Over-firing on questions that are correctly answered at the applied layer

Most questions do not have a governing formal result worth finding, and descending on every one
wastes a session. If this skill starts firing on routine lookups, the trigger list is too broad —
tighten it to formal objects, novelty claims, and repeated same-layer sweeps.

**Watch for:** a session that produces a literature descent and no decision change.

## [ANTICIPATED] Descending into a layer nobody can evaluate

Reaching the theorem is only useful if its boundary conditions can be checked against the actual
problem. A sweep that returns a formal result the team cannot apply has moved the problem, not
solved it.

**Watch for:** a cited theorem with no statement of which case the current problem falls into.

## [ANTICIPATED] Using "what is this an instance of?" to launder speculation

The question is a search prompt, not a licence to assert a correspondence. Claiming problem X *is*
formal object Y requires showing the definitions line up, not noticing they rhyme.

**Watch for:** an asserted correspondence with no side-by-side of the two definitions, and no
statement of which primaries were actually read versus reached through a summary.
